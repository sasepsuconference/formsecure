# formsecure

**formseucure** is a website to create and fill out forms securely. It allows users to send sensitive information securely and store it securely. Users also have the option to delete information that responds and to delete your own information/responses.

## Quick Start

### Requirements
 - NodeJS
 - PIP
 - Python3

### Local Deployment

1) If formsecure is not yet on your computer, run:

    ```
    git clone TODO
    ```

2) When formsecure is installed, navigate to the project root: 

    ```
    cd /path/to/formsecure/
    ```

3) To run the frontend:

    ```
    npm start
    ```

4) To run the backend, open another terminal and navigate to `/path/to/formsecure/` to run:

    ```
    python3 app.py
    ```

5) Enter the API keys to your database into `.env`
